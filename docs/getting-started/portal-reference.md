Quick facts about the [REANNZ HPC Portal](https://hpc-portal.reannz.co.nz).
For a guided walk-through, see [Tour the HPC Portal](portal-overview.md).

## Roles

| Role | Who holds it | What they can do |
| --- | --- | --- |
| Project member | Researchers on a project | View the project and its resources. |
| Project manager | The project owner or PI | Order resources, change resource limits and request an end date change. |
| Organisation owner | Nominated staff at your institution | Approve requests from projects in their organisation and set end dates directly. See [Approving requests](../institution-admins/approve-requests.md). |

## Sidebar

| Section | Contents |
| --- | --- |
| **Organisations** | The institutions you belong to. |
| **Projects** | Every project you are a member of. |
| **Resources** | Your allocations, grouped by type, for example **HPC** for Mahuika and **Storage** for Freezer. |
| **REANNZ Marketplace** | The services on offer. |
| **Calls** | Calls for proposals and your proposals. |

## Roles and permissions table

Shown on your **User dashboard**.

| Column | Meaning |
| --- | --- |
| Scope type | Whether the role is on a project or an organisation. |
| Scope name | The project or organisation name. Click it to open it. |
| Organisation | The institution that owns the project. |
| Role name | Your role, for example *Project manager* or *Project member*. |

## Project page

Project cards under **Projects** show the name, **Organisation**, **Resources** and **End date**.
Click **Details** to open a project.

| Tab | Contents |
| --- | --- |
| **Project dashboard** | Description, team summary and usage views. |
| **Resources** | The allocations the project holds. |
| **Team** | The project members. |
| **Audit logs** | A record of changes to the project. |

### Team tab

| List | Contents |
| --- | --- |
| **Active** | Each **Member**, their **Email**, **Role in project** and any **Role expiration**. |
| **Invitations** | People invited who have not yet joined. |

## Resource page

| Field | Meaning |
| --- | --- |
| Offering | The service, for example **Mahuika** or **Freezer**. |
| **Termination date** | When the allocation ends. |
| Usage | Current usage against each limit, for example compute, project storage and scratch storage. |
| **Usage history** | A chart of usage over time. |
| **Actions** | What you can do with the resource. Options depend on your role. |
| **End date change requests** | Tab listing **Pending** and **All** end date requests. |

### Actions by role

| Action | Who can use it |
| --- | --- |
| **Change limits** | Project manager |
| **Request end date change** | Project manager |
| **Set termination date** | Organisation owner |
| **Approve** / **Decline** an order | Organisation owner |
