## Release Update - 23 November 2026

## New and Improved

- The portal now runs Waldur 8.1.5-rc.3.
- Resource pages have a new layout. **Access resource** is now the main button. Usage and limits show totals for the whole order period.
- The change limits dialog lists components and limits in a table. See [Change allocation limits](../project-managers/change-limits.md).
- The portal has a refreshed look. Buttons, tables and forms are more consistent.

## Fixes

- Number fields in forms accept decimals and show errors again.
- Editing a pending order now runs the same checks as a new order.
- Turning off the project digest email now works.

## Security

- Sign-in no longer matches an account by an email address its user set themselves.
- The portal sends stricter browser security headers.
- Updated libraries fix known vulnerabilities.

If you have any questions about any of the improvements or fixes,
