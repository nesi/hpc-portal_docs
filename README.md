# HPC Portal documentation

User documentation for the [REANNZ HPC Portal](https://hpc-portal.reannz.co.nz/).

Published at <https://nesi.github.io/hpc-portal_docs/>.

## Local preview

Needs [uv](https://docs.astral.sh/uv/) and Python 3.11+.

```sh
uv sync
uv run zensical serve
```

Open <http://localhost:8000>.
